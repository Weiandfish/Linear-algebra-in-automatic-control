# 练习与公式速查 / Exercises and Formula Reference

[阅读导航 / Guide](00_阅读导航.md) · [特征值 / Eigenvalues](01_特征值与不变子空间.md) · [自然标准形 / Natural normal form](02_相似不变量与自然标准形.md)

**中文：** 以下 8 题为教学补充，具体计算在复数域上进行。先写出使用的定义，再计算；特征向量要分清抽象向量与坐标列。

**English:** These eight exercises are teaching supplements over the complex field. State the relevant definitions before computing, and distinguish abstract eigenvectors from coordinate columns.

## 练习 / Exercises

### 1. 不变子空间是否一定是特征空间 / Must an invariant subspace be an eigenspace?

**题目：** 在 $\mathbb C_2[t]$ 上取微分算子 $D$。$W=\operatorname{span}\{1,t\}$ 是否不变？是否为某个特征空间？

**Question:** For differentiation $D$ on $\mathbb C_2[t]$, is $W=\operatorname{span}\{1,t\}$ invariant? Is it an eigenspace?

**解：** $D(1)=0$、$D(t)=1$，故不变。但 $D$ 唯一特征值为 $0$，且 $E_0(D)=\operatorname{span}\{1\}\ne W$，所以不是特征空间。

**Answer:** It is invariant because $D(1)=0$ and $D(t)=1$. However, zero is the only eigenvalue and its eigenspace consists of constants, so $W$ is not an eigenspace.

### 2. 换基后特征向量的坐标 / Eigenvector coordinates after a basis change

**题目：** 取 $A=\begin{bmatrix}1&1\\0&1\end{bmatrix}$、$P=\begin{bmatrix}0&1\\1&1\end{bmatrix}$。求 $B=P^{-1}AP$，以及 $A$ 的特征向量 $e_1$ 在新基下的坐标。

**Question:** For these $A,P$, find $B=P^{-1}AP$ and the new coordinates of the eigenvector $e_1$ of $A$.

$$
B=\begin{bmatrix}0&-1\\1&2\end{bmatrix},\qquad
P^{-1}e_1=\begin{bmatrix}-1\\1\end{bmatrix}.
$$

**解：** 检查 $AP=PB$；$B(-1,1)^T=(-1,1)^T$，所以仍对应特征值 $1$。抽象向量为 $P(-1,1)^T=e_1$。

**Answer:** Verify $AP=PB$ and $B(-1,1)^T=(-1,1)^T$. The eigenvalue remains one and the abstract vector remains $P(-1,1)^T=e_1$.

### 3. 代数重数与几何重数 / Algebraic versus geometric multiplicity

**题目：** 微分算子在基 $(1,t,t^2)$ 下的矩阵为 $N=\begin{bmatrix}0&1&0\\0&0&2\\0&0&0\end{bmatrix}$。求全部特征值、两种重数，并判断是否可对角化。

**Question:** For this differentiation matrix, find all eigenvalues, both multiplicities and whether it is diagonalizable.

**解：** 特征多项式为 $\mu^3$；$0$ 的代数重数为 $3$。解 $Nx=0$ 得 $x_2=x_3=0$，几何重数为 $1$，不可对角化。非零常数多项式是全部特征向量。

**Answer:** The characteristic polynomial is $\mu^3$, so zero has algebraic multiplicity three. Its kernel is one-dimensional, so geometric multiplicity is one and it is not diagonalizable. All eigenvectors are nonzero constant polynomials.

### 4. 平移矩阵的列 / Columns of a translation matrix

**题目：** 在 $\mathbb C_2[t]$ 上，$T(f)(t)=f(t+2)$。求基 $(1,t,t^2)$ 下的矩阵与全部特征向量。

**Question:** For $T(f)(t)=f(t+2)$ on $\mathbb C_2[t]$, find its matrix in $(1,t,t^2)$ and all eigenvectors.

$$
T(1)=1,\quad T(t)=t+2,\quad T(t^2)=t^2+4t+4,
\qquad [T]=\begin{bmatrix}1&2&4\\0&1&4\\0&0&1\end{bmatrix}.
$$

**解：** 唯一特征值为 $1$；解 $([T]-I)x=0$ 得 $x_2=x_3=0$，故全部特征向量为 $f(t)=c\ne0$。

**Answer:** One is the only eigenvalue. The kernel of $[T]-I$ consists of coordinate columns $(c,0,0)^T$, so all eigenvectors are nonzero constants.

### 5. 矩阵幂的逆向推理 / A converse about matrix powers

**题目：** 对 $A=\operatorname{diag}(1,-1)$、$v=(1,1)^T$，$v$ 是 $A$ 的特征向量吗？是 $A^2$ 的特征向量吗？

**Question:** For $A=\operatorname{diag}(1,-1)$ and $v=(1,1)^T$, is $v$ an eigenvector of $A$? Of $A^2$?

**解：** $Av=(1,-1)^T$ 不是 $v$ 的倍数，所以不是 $A$ 的特征向量；但 $A^2=I$，故 $v$ 是 $A^2$ 的特征向量，特征值为 $1$。不同特征值的幂可能合并，逆向结论不成立。

**Answer:** It is not an eigenvector of $A$, but it is one of $A^2=I$, with eigenvalue one. Distinct eigenvalues can have equal powers, so the converse fails.

### 6. 写列伴随矩阵 / Constructing a column companion matrix

**题目：** 对 $\psi(\mu)=\mu^3-2\mu+3$，写出列伴随矩阵与其特征矩阵的 Smith 形。

**Question:** Construct the column companion matrix for $\psi(\mu)=\mu^3-2\mu+3$ and the Smith form of its characteristic matrix.

$$
C(\psi)=\begin{bmatrix}0&0&-3\\1&0&2\\0&1&0\end{bmatrix},\qquad
S_{\mu I-C(\psi)}=\operatorname{diag}(1,1,\mu^3-2\mu+3).
$$

**解：** 系数按 $(c_0,c_1,c_2)=(3,-2,0)$ 排列，最后一列取负，次对角线放 $1$。

**Answer:** Order the coefficients as $(c_0,c_1,c_2)=(3,-2,0)$, negate them in the last column and place ones on the subdiagonal.

### 7. 从 Smith 形构造自然标准形 / From Smith form to natural normal form

**题目：** 已知三阶常数矩阵 $A$ 的特征矩阵的 Smith 形为 $\operatorname{diag}(1,\mu-1,(\mu-1)(\mu+2))$，求自然标准形。

**Question:** A three-by-three constant matrix has characteristic-matrix Smith form $\operatorname{diag}(1,\mu-1,(\mu-1)(\mu+2))$. Find its natural normal form.

**解：** 舍去单位项；两个非常数项的次数为 $1,2$，块大小总和为 $3$。因 $(\mu-1)(\mu+2)=\mu^2+\mu-2$，有

**Answer:** Remove the unit entry. The remaining degrees are one and two, totaling three. Since $(\mu-1)(\mu+2)=\mu^2+\mu-2$,

$$
N=\operatorname{diag}\left([1],\begin{bmatrix}0&2\\1&-1\end{bmatrix}\right)
=\begin{bmatrix}1&0&0\\0&0&2\\0&1&-1\end{bmatrix}.
$$

### 8. 算子的初等因子取自哪个矩阵 / Which matrix defines operator elementary divisors?

**题目：** 在 $\mathbb C_3[s]$ 上取微分算子 $D$，求它的初等因子、特征空间，以及使矩阵成为列伴随块的一组基。

**Question:** For differentiation on $\mathbb C_3[s]$, find its elementary divisors, eigenspace and a basis giving a column companion block.

$$
S_{\mu I-[D]}=\operatorname{diag}(1,1,1,\mu^4),\qquad
E_0(D)=\operatorname{span}\{1\},\qquad
\mathcal B=\left(\frac{s^3}{6},\frac{s^2}{2},s,1\right).
$$

**解：** 唯一初等因子为 $\mu^4$。在 $\mathcal B$ 下，求导依次送到下一个基向量，矩阵为 $C(\mu^4)$。直接把常数矩阵 $[D]$ 当作多项式矩阵求 Smith 形，只得到 $\operatorname{diag}(1,1,1,0)$，不能用它替代特征矩阵的计算。

**Answer:** The only elementary divisor is $\mu^4$. In $\mathcal B$, differentiation sends each basis vector to the next, giving $C(\mu^4)$. Smith reduction of the constant matrix $[D]$ itself would give $\operatorname{diag}(1,1,1,0)$ and cannot replace the characteristic-matrix calculation.

## 核心公式与条件 / Core formulas and conditions

| 内容 / Topic | 公式与条件 / Formula and conditions |
| --- | --- |
| 换基 / Basis change | $C=BP\Rightarrow A_C=P^{-1}A_BP$，$P$ 为常数可逆矩阵 / Constant invertible $P$ |
| 不变子空间 / Invariant subspace | $T(W)\subseteq W$，不要求相等 / Equality is not required |
| 特征空间 / Eigenspace | $E_\rho(T)=\ker(T-\rho I)$，特征向量须非零 / Eigenvectors exclude zero |
| 几何重数 / Geometric multiplicity | $g_\rho=d-\operatorname{rank}(A-\rho I)$ |
| 重数关系 / Multiplicities | $1\le g_\rho\le m_\rho$，$\rho$ 为特征值 / For an eigenvalue |
| 不同特征空间 / Distinct eigenspaces | 和为直和，未必等于全空间 / Direct sum, not necessarily the whole space |
| 特征向量坐标 / Eigenvector coordinates | $B=P^{-1}AP,\ Ax=\rho x\Rightarrow B(P^{-1}x)=\rho P^{-1}x$ |
| 相似判据 / Similarity test | 同阶常数矩阵 $A\sim B\iff\mu I-A$ 与 $\mu I-B$ 幺模等价 / For constant matrices of the same size |
| 自然标准形 / Natural normal form | $\operatorname{diag}(C(\psi_1),\ldots,C(\psi_\ell))$，$\psi_i$ 来自特征矩阵 / Invariants belong to the characteristic matrix |
| 维数检查 / Dimension check | $\sum_i\deg\psi_i=d$，只计算非常数不变多项式 / Count nonconstant invariants only |
| 验证换基 / Verify a basis change | $AP=PN$ 且 $P$ 可逆 / Invertible $P$ |

**中文：** 自查顺序：先确定标量域与空间维数，再分清算子、矩阵和坐标；求特征向量时排除零向量；构造自然标准形时先取特征矩阵，舍去单位不变多项式，检查块大小总和。

**English:** Check the field and dimension first, then distinguish operators, matrices and coordinates. Exclude zero when listing eigenvectors. For natural normal form, start with the characteristic matrix, discard unit invariant polynomials and check the total block size.
