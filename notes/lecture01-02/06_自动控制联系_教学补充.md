## 与自动控制的一个连接 / One connection to automatic control

> 教学补充 / Teaching supplement；用于解释课程标题，不是这两讲新增的原讲义定理 / This explains the course title and is not an additional theorem stated in these two lectures。

**中文：** 在线性状态方程中，状态 $x$ 是状态空间的一组坐标。若选择新的状态基，令 $x=Pz$ 且 $P$ 为常数可逆矩阵，则系统矩阵按刚才的规则变化。下面用下标 $s$ 区分系统矩阵和前文的基符号。

**English:** In a linear state-space equation, the state $x$ is a coordinate description of the state. Choose a new state basis by setting $x=Pz$, where $P$ is constant and invertible. The system matrices then change according to the rules just derived. The subscript $s$ distinguishes system matrices from earlier basis notation.

$$
\dot x=A_sx+B_su,\qquad y=C_sx+D_su.
$$

$$
P\dot z=A_sPz+B_su
\quad\Longrightarrow\quad
\boxed{\dot z=P^{-1}A_sPz+P^{-1}B_su},\qquad
\boxed{y=C_sPz+D_su}.
$$

**中文：** 这正是“基改变了，坐标和矩阵描述随之改变”。物理状态由 $x=Pz$ 对应，新坐标仍描述同一个系统。常数 $P$ 的条件在此不可省略；本节不讨论随时间变化的基。

**English:** This is exactly a basis change accompanied by changes in coordinates and matrix descriptions. The physical state corresponds through $x=Pz$, so the new coordinates describe the same system. The assumption that $P$ is constant is essential here; time-varying bases are outside this example.

**中文：** 子空间同样有直接意义。例如 $\operatorname{im}B_s$ 表示输入项 $B_su$ 在某一时刻能够提供的状态变化方向；$\ker B_s$ 表示被输入矩阵映成零的输入组合。理解核、像和换基，是以后学习系统分解与控制理论的准备。

**English:** Subspaces also have a direct interpretation. For example, $\operatorname{im}B_s$ describes state-change directions contributed by the input term $B_su$ at a given instant, while $\ker B_s$ describes input combinations annihilated by the input matrix. Kernels, images, and basis changes prepare you for later system decompositions and control theory.
