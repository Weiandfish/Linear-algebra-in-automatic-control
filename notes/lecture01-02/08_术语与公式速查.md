# 术语与公式速查 / Terminology and formula reference

|---|---|---|

| 封闭性 | Closure | 输出留在规定集合 / Outputs remain in the specified set |
| 交换律 | Commutativity | 交换输入顺序不改变结果 / Reversing inputs preserves the result |
| 结合律 | Associativity | 改括号不改结果 / Regrouping preserves the result |
| 分配律 | Distributivity | 乘法分配到加法 / Multiplication distributes over addition |

| 群 | Group | 一个运算满足群公理 / One operation satisfying group axioms |
| 交换群 | Abelian group | 满足交换律的群 / A commutative group |
| 环 | Ring | 具有相容的加法和乘法 / Compatible addition and multiplication |
| 零因子 | Zero divisor | 非零元素可与非零元素乘出零 / A nonzero factor in a zero product |
| 整环 | Integral domain | 没有零因子的交换环 / A commutative ring without zero divisors |

| 数乘 | Scalar multiplication | 标量作用于向量 / Multiplication of a vector by a scalar |
| 线性组合 | Linear combination | 数乘后相加 / A sum of scalar multiples |
| 线性相关 | Linearly dependent | 存在非平凡零组合 / A nontrivial zero combination exists |

| 维数 | Dimension | 一组基的向量数 / Number of vectors in a basis |

## 核心公式 / Core formulas

| 用途 / Purpose | 公式及条件 / Formula and conditions |
|---|---|
| 判断无关 / Test independence | $\sum k_iv_i=0\Rightarrow k_i=0$ for all $i$ |
| 多项式空间维数 / Polynomial dimension | $\dim\mathbb F_{n-1}[\lambda]=n$ |
| 过渡矩阵的定义 / Define the transition matrix | $C=BP$，第 $j$ 列为 $[c_j]_B$ / Column $j$ is $[c_j]_B$ |
| 坐标换基 / Convert coordinates | $[v]_B=P[v]_C$，$[v]_C=P^{-1}[v]_B$ |
| 生成空间维数 / Dimension of a span | $\dim\operatorname{span}\{v_i\}=\operatorname{rank}[v_1\ \cdots\ v_s]$ |
| 和的维数 / Dimension of a sum | $\dim(U+W)=\dim U+\dim W-\dim(U\cap W)$ |
| 两空间的直和 / Direct sum of two subspaces | $U\cap W=\{0\}$ |
| 线性性 / Linearity | $T(au+bv)=aT(u)+bT(v)$ |
| 映射矩阵 / Matrix of a mapping | $A=\big[[T(b_1)]_C\ \cdots\ [T(b_n)]_C\big]$ |
| 输入、输出坐标关系 / Input–output coordinates | $[T(u)]_C=A[u]_B$ |
| 秩–零度，有限维输入 / Rank–nullity, finite-dimensional domain | $\dim U=\dim\ker T+\dim\operatorname{im}T$ |
| 单射 / Injectivity | $T$ injective $\Longleftrightarrow\ker T=\{0\}$ |
| 映射的两侧换基 / Independent basis changes | $B'=BP,\ C'=CQ\Rightarrow A'=Q^{-1}AP$ |
| 同一空间同一换基 / Same-space basis change | $A'=P^{-1}AP$ |

## 常见错误纠正 / Common mistakes corrected

| 常见错误 / Mistake | 正确理解 / Correction |
|---|---|
| 矩阵乘法结合，所以也交换 / Associative means commutative | 两条性质独立，矩阵通常 $AB\ne BA$ / The properties are distinct |
| 所有非零矩阵都可逆 / Every nonzero matrix is invertible | 非零仍可能奇异 / A nonzero matrix may be singular |
| 向量只能是数字列 / Vectors must be numerical columns | 矩阵、多项式也可以是向量 / Matrices and polynomials can be vectors |
| 次数恰好为 $n$ 的多项式是空间 / Exact-degree polynomials form a space | 要使用次数至多为 $n$，且包含零 / Use bounded degree and include zero |
| 相关要求所有系数都非零 / Dependence requires every coefficient nonzero | 只需系数不全为零 / Only not all zero is required |
| 两两不平行就一定无关 / Pairwise nonparallel implies independence | 三个以上向量仍可能整体相关 / A larger list may still be dependent |
| 无关就一定是整个空间的基 / Independence alone gives a basis | 还必须生成所讨论的空间 / It must also span the space in question |
| 换基会改变向量本身 / Changing basis changes the vector | 改变的是坐标描述 / It changes the coordinates |
| 基怎么乘，坐标就怎么乘 / Bases and coordinates change in the same direction | $C=BP$ 对应新坐标 $P^{-1}[v]_B$ / Coordinates use the inverse |
| 子空间只要包含原点即可 / Containing zero suffices | 还要对加法、数乘封闭 / Closure is also required |
| 子空间的并总是子空间 / A union of subspaces is always a subspace | 对两个子空间，需一方包含另一方 / One must contain the other |
| 和的维数直接相加 / Dimensions always add under a sum | 必须扣掉交的维数 / Subtract the intersection dimension |
| 任意和都有唯一分解 / Every sum gives unique decomposition | 直和才保证两部分唯一 / A direct sum guarantees uniqueness |
| 补空间等于正交补 / A complement is an orthogonal complement | 一般补空间不要求正交 / General complements need not be orthogonal |
| $T(0)=0$ 就线性 / Preserving zero proves linearity | 仍需验证一般线性组合 / Verify arbitrary linear combinations |
| 无关向量的像必无关 / Independent vectors always have independent images | 一般不成立；单射时成立 / This holds for injective maps |
| 像就是整个输出空间 / Image equals codomain | 像可能只是陪域的子空间 / The image may be a proper subspace |
| 映射矩阵总是方阵 / Mapping matrices are always square | 行数是输出维数，列数是输入维数 / Rows count outputs; columns count inputs |
| 用基向量作矩阵列 / Basis vectors themselves are matrix columns | 应用输入基向量的像在输出基下的坐标 / Use coordinates of input-basis images |

## 做题时的五个步骤 / Five useful problem-solving routines

**中文：** 判断空间或子空间：先明确标量域和运算；再检查零对象；最后取任意两个元素与任意标量，验证线性组合仍在集合中。若定义的是全新运算，需要验证完整的空间公理，不能只用继承运算的子空间判定。

**English:** To test a space or subspace, specify the field and operations, check the zero object, and then test arbitrary linear combinations. For newly defined operations, verify the full vector-space axioms; the inherited-operation subspace test alone is insufficient.

**中文：** 求基与维数：把生成向量写成列，行化简，找主元列，在原矩阵中选对应列。主元数就是秩，也是生成空间的维数。

**English:** To find a basis and dimension, place generators in columns, row-reduce, identify pivot columns, and select the corresponding original columns. The number of pivots is the rank and the span dimension.

**中文：** 求坐标：写出“向量等于基向量的线性组合”，解系数。求换基：先写 $C=BP$，再由同一向量的两种表达推导坐标关系，最后重构向量检验。

**English:** To find coordinates, express the vector as a combination of basis vectors and solve for coefficients. For a basis change, write $C=BP$, derive the coordinate relation from two expressions for the same vector, and check by reconstruction.

**中文：** 求映射矩阵：先确认输入基和输出基；逐个求输入基向量的像；把每个像改写成输出基坐标；按列拼接；最后用一个向量核对 $[T(u)]_C=A[u]_B$。

**English:** To find a mapping matrix, specify both bases, map each input basis vector, compute its output-basis coordinates, concatenate these columns, and check $[T(u)]_C=A[u]_B$ on an input vector.

**中文：** 证明定理：先写出要证明的条件，再回到定义。例如证明“唯一”就假设两种表示并相减；证明“子空间”就检查零与线性组合；证明“不是”就寻找反例。理解定义如何驱动证明，比单独记住结论更有用。

**English:** To prove a statement, write the required conditions and return to the definitions. For uniqueness, subtract two proposed representations; for subspaces, test zero and linear combinations; to disprove a claim, find a counterexample. Understanding how definitions drive proofs is more useful than recalling isolated conclusions.
