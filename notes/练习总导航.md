本目录汇总 11 份练习文件，共 118 条题目与解答，包含中文综合版中的对应练习。题目补齐空间、标量域、基、映射和内积等条件；解答按步骤展开，给出所用定义、一般元素、具体计算与结果检验。各讲双语版保留中英对照，中文综合版保留中文讲解。

第一次接触这些内容，先读[练习中的符号与做题方法](练习阅读说明.md)，再从第一至第三讲开始。看每道解答时，先确认“已知的对象是什么、要求算什么”，再跟着等式推导。

## 遇到不同问题时先找哪一步？

| 问题 | 解答中应找到的步骤 |
| --- | --- |
| 不知道为什么能写 $p=a+b\lambda+c\lambda^2$ | 看空间定义与“一般输入” |
| 不知道矩阵每一列从哪里来 | 找输入基的像，再看输出基下的坐标 |
| 核与像只看到 span，不知道怎么算 | 看零输出方程、自由参数、任意输出的原像 |
| 过渡矩阵的方向容易弄反 | 看新旧坐标关系与 $AP=PA'$ 的检验 |
| Smith 形只记住了结论 | 看具体子式、最大公因式、相邻商与整除链 |
| Jordan 块长、块数、维数分不清 | 看指数、核维数第一差分、各块占据的维数 |
| 正交化的系数不知从哪来 | 看内积、投影系数、残差长度和归一化 |
| 定理的条件被省略了 | 看题干中的标量域、满秩、Hermitian、正交规范基等前提 |
