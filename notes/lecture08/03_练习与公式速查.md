# 练习与公式速查 / Exercises and Formula Reference

[阅读导航 / Guide](00_阅读导航.md) · [上一章 / Previous](02_循环子空间与第二分解.md)

> 以下均为教学补充练习。除特别说明外，在复数域和有限维空间中讨论，最小多项式均首一化。 / These are supplementary exercises over the complex field in finite dimension unless stated otherwise. All minimal polynomials are monic.

## 一、八道练习及答案 / Eight exercises with answers

### 1. 向量处与全空间 / A vector and the whole space

**题目：** $T=\operatorname{diag}(1,2)$。求 $m_{e_1}$、$m_{e_1+e_2}$、$m_T$。 / **Problem:** Find these three minimal polynomials for $T=\operatorname{diag}(1,2)$.

**解答：** $p(T)(e_1+e_2)=p(1)e_1+p(2)e_2$，必须同时有 $p(1)=p(2)=0$。因此 / **Answer:** The displayed vector vanishes exactly when both evaluations vanish. Thus

$$
m_{e_1}=z-1,\qquad m_{e_1+e_2}=m_T=(z-1)(z-2).
$$

### 2. 分块矩阵不能总取乘积 / A block lcm is not always a product

**题目：** $A=\operatorname{diag}(J_2(1),[1],[-2])$。求最小多项式和特征多项式。 / **Problem:** Find the minimal and characteristic polynomials of this block matrix.

**解答：** 各块最小多项式为 $(z-1)^2,z-1,z+2$。最小多项式取最小公倍式，特征多项式取各块特征多项式的乘积。 / **Answer:** The block minimal polynomials are $(z-1)^2,z-1,z+2$. Take their lcm for the minimal polynomial and multiply block characteristic polynomials for the characteristic polynomial.

$$
m_A=(z-1)^2(z+2),\qquad \chi_A=(z-1)^3(z+2).
$$

### 3. 指数与广义特征空间维数 / Exponents and primary dimensions

**题目：** 在根 $-3$ 处块长为 $1,1,2$，在根 $-2+5i$ 和 $-2-5i$ 处各为 $1,2$。求整体维数、最小多项式、三个广义特征空间维数。 / **Problem:** Given these block sizes at the three roots, find the total dimension, minimal polynomial and three primary dimensions.

**解答：** 总维数为 $4+3+3=10$；每个根的最大块长为 $2$，广义特征空间维数则对块长求和。 / **Answer:** The total dimension is ten. Each largest block has size two, whereas each primary dimension sums all block sizes at its root.

$$
m_A=(z+3)^2((z+2)^2+25)^2,\qquad
(\dim G_{-3},\dim G_{-2+5i},\dim G_{-2-5i})=(4,3,3).
$$

**中文：** 此处 $G_\rho=\ker(A-\rho I)^2$；不能把维数都写为 $2$。 / **English:** Here $G_\rho=\ker(A-\rho I)^2$; the exponent two is not the dimension.

### 4. 直接检验最小性 / Checking minimality directly

**题目：** $A=\begin{bmatrix}2&1\\0&2\end{bmatrix}$。证明最小多项式为 $(z-2)^2$。 / **Problem:** Prove that this matrix has minimal polynomial $(z-2)^2$.

**解答：** $A-2I\ne0$，但 $(A-2I)^2=0$。任何一次首一零化多项式只能为 $z-2$，它并不零化。 / **Answer:** The first power of $A-2I$ is nonzero and the second is zero. The only possible monic linear annihilator is $z-2$, which fails. Hence the square is minimal.

### 5. 判断循环向量 / Testing a cyclic vector

**题目：** 令

$$
A=\begin{bmatrix}1&1&0\\0&1&0\\0&0&2\end{bmatrix},\qquad
v=\begin{bmatrix}0\\1\\1\end{bmatrix}.
$$

判断 $v$ 与 $e_1$ 是否分别生成整个空间。 / **Problem:** Determine whether each of $v,e_1$ generates the whole space.

**解答：** / **Answer:**

$$
P=(v,Av,A^2v)=\begin{bmatrix}0&1&2\\1&1&1\\1&2&4\end{bmatrix},
\qquad\det P=-1.
$$

**中文：** 所以 $v$ 为循环向量，$m_v=m_A=(z-1)^2(z-2)$。而 $Ae_1=e_1$，故 $\mathcal S_A[e_1]=\operatorname{span}\{e_1\}$，不是全空间。 / **English:** Thus $v$ is cyclic and attains the degree-three minimal polynomial. Since $Ae_1=e_1$, the cyclic subspace of $e_1$ has dimension one.

### 6. 实际构造平移的 Jordan 基 / Constructing a translation Jordan basis

**题目：** 在 $\mathbb C_2[s]$ 中令 $Tf(s)=f(s+2)$，用基 $(1,s,s^2)$ 表示，求 $X$ 使 $X^{-1}AX=J_3(1)$。 / **Problem:** Find a Jordan basis and its coordinate matrix for translation by two.

**解答：** 取 $f_0=1,f_1=s/2,f_2=s(s-2)/8$。 / **Answer:** Use these Newton polynomials. They satisfy $Tf_0=f_0$ and $Tf_k=f_k+f_{k-1}$.

$$
A=\begin{bmatrix}1&2&4\\0&1&4\\0&0&1\end{bmatrix},\qquad
X=\begin{bmatrix}1&0&0\\0&1/2&-1/4\\0&0&1/8\end{bmatrix},
\qquad AX=XJ_3(1).
$$

**中文：** $\det X=1/16\ne0$，列的顺序与超对角线上为 $1$ 的 Jordan 约定一致。 / **English:** The determinant is $1/16$, and this column order matches superdiagonal ones in the Jordan block.

### 7. 广义特征向量的精确阶数 / Exact generalized-eigenvector order

**题目：** 仍令 $Tf(s)=f(s+2)$，$f(s)=3s^2-s+4$，$\Delta=T-I$。求 $f$ 的广义特征阶数和 $m_f$。 / **Problem:** Find the exact order and local minimal polynomial of this polynomial.

**解答：** / **Answer:**

$$
\Delta f=12s+10,\qquad \Delta^2f=24,\qquad \Delta^3f=0.
$$

**中文：** 因此它是特征值 $1$ 的三阶广义特征向量，$m_f=(z-1)^3$。阶数从 $1$ 开始，非零常数的阶数为 $1$。 / **English:** It has exact order three at eigenvalue one, so $m_f=(z-1)^3$. Orders start at one; nonzero constants have order one.

### 8. 第一分解与第二分解 / First versus second decomposition

**题目：** 第 7 次作业第 4 题的非平凡不变多项式为 $x,x^2q,x^2q^2$，其中 $x=z+1,q=(z+1)^2+1$。比较两种分解的分量维数。 / **Problem:** Compare the component dimensions in the two decompositions for these invariant polynomials.

**解答：** 第一分解按根 $-1,-1-i,-1+i$ 分组，维数为 $5,3,3$；第二分解按三个不变多项式给出循环分量，维数为 $1,4,6$。 / **Answer:** The first decomposition groups roots and has dimensions $5,3,3$. The second uses the invariant polynomials and has cyclic dimensions $1,4,6$.

$$
5+3+3=1+4+6=11.
$$

**中文：** 两者都为不变直和，但分组标准不同。不是每个广义特征空间都循环，例如根 $-1$ 有三个 Jordan 块。 / **English:** Both are invariant direct sums, but they group components differently. A primary space need not be cyclic; the root $-1$ here has three blocks.

## 二、公式与条件速查 / Formulas and conditions

| 用途 / Purpose | 公式与条件 / Formula and conditions |
| --- | --- |
| 向量处零化 / Local annihilation | $p(T)v=0\iff m_v\mid p$；$m_0=1$ |
| 包含关系 / Inclusion | $U\subseteq W\Rightarrow m_U\mid m_W$ |
| 子空间处 / At a subspace | $m_W=\operatorname{lcm}_i m_{w_i}$，$(w_i)$ 是基 / a basis |
| 相似不变 / Similarity | $m_{X^{-1}AX}=m_A$，$X$ 可逆 / invertible |
| 最大不变多项式 / Largest invariant | $m_A=d_d=\chi_A/D_{d-1}$，$d\ge1,D_0=1$ |
| 分块 / Blocks | $m_{\operatorname{diag}(A_i)}=\operatorname{lcm}_i m_{A_i}$ |
| Jordan 判据 / Jordan test | $m_A=\prod_\rho(z-\rho)^{b_\rho}$，在复数域且 $b_\rho$ 为最大块长 / over $\mathbb C$, with largest block sizes |
| 第一分解 / First decomposition | $W=\bigoplus_i(W\cap\ker\varphi_i(T))$，$W$ 不变且 $m_W=\prod_i\varphi_i$ 两两互素 / invariant $W$, pairwise coprime factors |
| 循环维数 / Cyclic dimension | $\dim\mathcal S_T[v]=\deg m_v$ |
| 整体循环 / Whole-space cyclicity | $T$ 循环 $\iff\deg m_T=\dim V$ / $T$ is cyclic iff the degrees agree |
| 第二分解 / Second decomposition | $V=\bigoplus_i\mathcal S_T[\beta_i]$，$m_{\beta_i}=\psi_i$，$\psi_i$ 为非平凡不变多项式 / nonconstant invariant polynomials |
| 平移算子 / Translation | $m_T=(z-1)^{n+1}$，在 $\mathbb C_n[s]$ 上且 $a\ne0$ / on $\mathbb C_n[s]$, $a\ne0$ |

**中文：** 做题时先确认空间维数和系数域，再区分求的是向量处还是整体最小多项式。求出 $X$ 后直接验证 $AX=XJ$，通常比先求逆更方便。 / **English:** First check the dimension and field, then distinguish local from global minimal polynomials. Verify a proposed change of basis through $AX=XJ$, usually without computing an inverse.
