**English:** Slide 11 repeats the coordinate derivation on slide 10, so the notes give it once. Three typographical errors deserve attention: transitivity on slide 17 should conclude $C\cong A$; the preimage in the surjectivity definition on slide 19 belongs to the domain $U$; and the matrix from a $p$-dimensional space to an $m$-dimensional space on slide 27 has size $m\times p$. The chapters use the correct definitions and dimensions.

## 先复习什么 / Prerequisites

**中文：** 先确认自己能完成三件事：判断一个集合是否对子空间运算封闭；把向量表示成指定基的线性组合；用“新基 = 旧基 × 过渡矩阵”写出换基关系。对应前两讲的 [基与换基](../lecture01-02/03_基与换基.md)、[线性子空间](../lecture01-02/04_线性子空间.md) 和 [线性映射](../lecture01-02/05_线性映射与矩阵表示.md)。

**English:** Check that you can test closure for a subspace, express a vector as a linear combination of a specified basis, and write a basis change as “new basis = old basis × transition matrix.” Review [Bases and Changes of Basis](../lecture01-02/03_基与换基.md), [Linear Subspaces](../lecture01-02/04_线性子空间.md), and [Linear Mappings](../lecture01-02/05_线性映射与矩阵表示.md) if needed.

## 学完应当会做什么 / Learning goals

| 中文 | English |
| --- | --- |
| 检查 $T(au+bv)=aT(u)+bT(v)$，并能写出证明。 | Check linearity and write a proof. |
| 用指定输出基下的像坐标构造矩阵的列。 | Build matrix columns from image coordinates in the specified output basis. |
| 分清 $Q^{-1}AP$、$P^{-1}AP$ 与一般等价关系。 | Distinguish independent basis changes, similarity, and general equivalence. |
| 用单射、满射或维数证明同构。 | Prove isomorphism using injectivity, surjectivity, or dimension. |
| 求核与像，并把坐标答案还原成空间中的向量。 | Find kernel and range, then reconstruct the actual vectors from coordinates. |
| 按先后顺序写复合映射和矩阵乘积。 | Write compositions and matrix products in the correct order. |
