## 核心公式 / Core formulas

**中文：** 设 $\dim U=n$、$\dim V=m$，输入基为 $B$、输出基为 $C$，矩阵为 $A=[T]_{C\leftarrow B}$。下面的换基约定始终是“新基 = 旧基 × 过渡矩阵”。

**English:** Let $\dim U=n$, $\dim V=m$, with domain basis $B$, codomain basis $C$, and matrix $A=[T]_{C\leftarrow B}$. The transition convention throughout is “new basis = old basis × transition matrix.”

### 矩阵与坐标 / Matrices and coordinates

$$
A=\begin{bmatrix}[T(b_1)]_C&\cdots&[T(b_n)]_C\end{bmatrix}
\in\mathbb F^{m\times n},\qquad [T(u)]_C=A[u]_B.
$$

$$
[aT+bS]_{C\leftarrow B}=a[T]_{C\leftarrow B}+b[S]_{C\leftarrow B},\qquad
\dim\mathcal L(U\to V)=mn.
$$

### 换基 / Basis changes

$$
B'=BP,\ C'=CQ
\Longrightarrow [u]_B=P[u]_{B'},\quad
\boxed{A'=Q^{-1}AP}.
$$

$$
T:V\to V,\quad B'=BP
\Longrightarrow\boxed{A'=P^{-1}AP}.
$$

### 同构、核与像 / Isomorphism, kernel, and range

$$
\ker T=\{u:T(u)=0\},\qquad
\operatorname{im}T=\operatorname{span}\{T(b_1),\ldots,T(b_n)\}.
$$

$$
\boxed{\dim\ker T+\operatorname{rank}T=n},\qquad
\operatorname{rank}T=\operatorname{rank}A.
$$

$$
T\text{ injective}\iff\ker T=\{0\}\iff\operatorname{rank}A=n,
$$

$$
T\text{ surjective}\iff\operatorname{im}T=V\iff\operatorname{rank}A=m.
$$

**中文：** 对同维的有限维空间，给定的线性映射单射、满射、同构三个条件等价；对不同维空间不能这样合并。两个空间维数相同，表示存在同构，不表示所给映射必然同构。

**English:** Between finite-dimensional spaces of the same dimension, injectivity, surjectivity, and isomorphism of a specified linear map are equivalent. Do not merge these conditions for unequal dimensions. Equal dimensions imply that an isomorphism exists, not that the particular map given is an isomorphism.

### 复合 / Composition

$$
S:U\to W,\quad T:W\to V,\quad
[S]_{C\leftarrow B}=M,\quad [T]_{D\leftarrow C}=A
\Longrightarrow\boxed{[T\circ S]_{D\leftarrow B}=AM}.
$$

$$
C'=CP,\quad[S]_{C\leftarrow B}=M,\quad[T]_{D\leftarrow C'}=A'
\Longrightarrow [T\circ S]_{D\leftarrow B}=A'P^{-1}M.
$$

## 维数检查 / Dimension checks

| 对象 / Object | 大小或维数 / Size or dimension |
| --- | --- |
| 输入坐标 / Domain coordinates | $n\times1$ |
| 输出坐标 / Codomain coordinates | $m\times1$ |
| 映射矩阵 / Map matrix | $m\times n$ |
| 输入基过渡矩阵 / Domain transition | $n\times n$ |
| 输出基过渡矩阵 / Codomain transition | $m\times m$ |
| 核 / Kernel | $n-\operatorname{rank}A$ |
| 像 / Range | $\operatorname{rank}A$ |
| 从 $n$ 维经 $p$ 维到 $m$ 维 / Composition through dimension $p$ | $(m\times p)(p\times n)=m\times n$ |

## 做题前的五个提醒 / Five reminders before solving problems

| 中文 | English |
| --- | --- |
| $T(0)=0$ 不足以证明线性。 | Sending zero to zero does not prove linearity. |
| 映射的列是像在指定输出基下的坐标。 | Columns are image coordinates in the specified output basis. |
| 求像要取原矩阵的主元列，不是行最简形的列。 | Use pivot columns of the original matrix for the range. |
| 核的坐标用输入基还原，像的坐标用输出基还原。 | Reconstruct kernel coordinates in the domain basis and range coordinates in the codomain basis. |
| 复合先做右边，且中间坐标基必须衔接。 | Compose from right to left, with matching middle coordinate bases. |

**中文：** 推荐检验方法：换基后检查 $AP=QA'$；同一空间同步换基检查 $AP=PA'$；求核后代入 $Ax=0$；核与像求完检查“零度 + 秩 = 输入维数”。

**English:** Recommended checks: verify $AP=QA'$ after independent basis changes, or $AP=PA'$ for a simultaneous change on one space. Substitute kernel coordinates into $Ax=0$, and check “nullity + rank = domain dimension.”
