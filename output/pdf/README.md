A4 纸，选择实际大小（100%），建议双面、长边翻页。白底排版与浅色图解底减少耗墨；公式和图解保留矢量，黑白打印也可阅读。每份独立带封面、目录、章节书签和连续页码。

PDF 正文依次编号为第一至第十八章，与原 Markdown 的知识点阅读顺序一致。原文件 16—20 在 PDF 中为第十四至第十八章；两份综合练习分别列为 A、B。屏幕阅读用的 Markdown 和黑底图片保持原样。
